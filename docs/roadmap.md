# 로드맵

## 예정: 종합 경로 안내

경로를 확정한 뒤, 여행 전체를 처음부터 끝까지 따라갈 수 있게 안내하는 기능.

- 확정된 경로의 모든 구간을 하나의 일정으로 이어서 보여주기 (지점별 예상 도착·출발 시각 포함)
- 구간 안의 세부 안내: 도보 거리, 탈 버스·지하철 노선, 승하차 정류장·역, 환승 지점
- 여행 중 현재 위치에 맞춰 지금 진행 중인 구간을 표시

준비할 것:
- TMAP 대중교통 응답의 세부 정보(노선명, 정류장, 구간별 시간)를 지금은 경로 좌표·수단만 남기고 버린다. 안내 기능을 만들 때 `LegInfo`에 세부 단계를 보존하도록 확장해야 한다.
- 자동차·도보 응답의 안내 지점(turn-by-turn) 정보도 같은 방식으로 보존.
